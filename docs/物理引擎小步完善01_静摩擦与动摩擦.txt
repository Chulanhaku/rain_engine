### 3. 行为变化

- 有摩擦的动态物体在实体表面上滑动会逐渐减速，低速且处于静摩擦预算内时可以停止相对滑动。
- 摩擦作用于相对速度，所以运动学表面可以带动接触的动态物体；静态或运动学物体不会被反向修改速度。
- 同时考虑 X/Z 切向速度的总长度，不分别对每个轴使用一份完整摩擦预算。
- 未设置新字段的旧物体继续保持原有行为；纯 collider 无 rigid_body 材料时视为摩擦系数 0。
- 样例初始即演示两方块滑动；C 只重播摩擦对照，R 仍重置完整场景。两者都从 x=-6、速度 +3 开始。

当前样例参数：
对象       static_friction  dynamic_friction  linear_damping
地面       0.8              0.6               原值（静态不积分）
铜色方块   0.8              0.6               0
冰蓝方块   0.04             0.02              0

双方系数按 sqrt(mu_A * mu_B) 混合，因此铜色接触的有效动摩擦为 0.6，冰蓝接触的有效动摩擦约为 0.10954。这里的“高/低摩擦”是物理参数，与 PBR 的 roughness 没有自动联动。

### 4. 风险点

- 这是当前平移物理 V0 上的速度级摩擦近似。没有接触流形、累计摩擦冲量或 warm start，多点接触和密集堆叠仍可能需要更完整的约束求解。
- 先积分位置、后做接触速度响应，停止距离会有固定步长带来的离散误差；静摩擦并非位置锁定约束，在持续切向外力下可能有微小位移。
- 目前没有角动力学；球体会减小平移滑动速度，但不会因此产生真实滚动，也未实现滚动摩擦。
- 没有法向冲量就没有本次摩擦预算；这是接触响应，不是任意表面的粘附力或空中阻尼。
- effective dynamic_friction = min(valid dynamic_friction, valid static_friction)。仅设置 dynamic_friction 而保留 static_friction=0 不会启用摩擦；请同时配置双方两个字段。
- 结构体新增字段导致二进制布局变化；本仓库已重新编译。未验证外部二进制插件或自定义裸内存序列化。
- 本轮验证为 GCC Debug / Windows D3D11；图形烟测验证运行、日志和可见物体数，未声称人工逐键交互或截图视觉验收。

### 6. 建议先理解的三个计算步骤

1. 分出法向和切向速度。
   接触法线 n 指向 first；相对速度 v = v_first - v_second。
   法向速度 vn = dot(v,n)，切向速度 vt = v - n*vn。
   旧代码解决的是法向穿透/反弹，本次增加的是切向滑动响应。

2. 计算预算。
   法向冲量 Jn = -(1+e)*vn / (inverse_mass_first + inverse_mass_second)。
   完全消除切向相对速度需要 Jstop = length(vt) / 两者逆质量之和。
   静摩擦预算为 mu_static * Jn。
   若 Jstop 在预算内，施加恰好停止的切向冲量；否则施加 mu_dynamic * Jn，并限制为不超过 Jstop。

3. 同时更新双方速度。
   摩擦方向与 vt 相反；两方收到等大反向的冲量，然后各自乘逆质量得到速度变化。
   因为使用相对速度，这同样适用于接触一个正在移动的运动学表面。

一个用于回归的独立例子：重力为 10、有效动摩擦 0.3、初速 2，持续滑动 0.5 秒后预期速度为 2 - 0.3*10*0.5 = 0.5；这条检查可以识别摩擦被重复施加或误用阻尼的问题。

建议阅读顺序：rigid_body_3d_component.hpp 的两个字段 → physics_world_3d.cpp 的 friction_of/combine_friction/resolve_collision → sample_3d_world_builder.cpp 的对照参数。先调高/调低冰蓝方块系数，再按 C 观察，便于判断这种参数组织和手感是否符合你的方向。
