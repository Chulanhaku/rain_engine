# 代码变更汇总

任务：修复立方体凹陷外观与面剔除
日期：2026-09-15

原因：d3d11_render_backend::create_pipeline_state 中，render_cull_mode::front 被映射为 D3D11_CULL_BACK，back 被映射为 D3D11_CULL_FRONT。正常单面 3D 材质请求剔除背面时，实际删除了靠近相机的外表面，留下远侧内壁，因此立方体看起来像凹进去的墙角。立方体的顶点绕序、法线和深度矩阵并无此错误。

- engine/render/src/d3d11/d3d11_render_backend.cpp（修改）

- engine/render/CMakeLists.txt（修改）
- tests/render_3d_tests.cpp（修改）
- tests/pbr_shader_tests.cpp（修改）
- docs/修复立方体凹陷外观与面剔除.txt（新增归档）

没有删除文件。此次 diff 以本轮修改前快照为基准，保留此前尚未提交的 Physics V0 工作。

## 2. 逐文件变更说明

### engine/render/src/d3d11/d3d11_render_backend.cpp
- 修改函数：d3d11_render_backend::create_pipeline_state。
- 改动：删除函数内前后面映射颠倒的 rasterizer 状态组装代码，调用 detail::make_d3d11_rasterizer_desc。加入该内部辅助函数的头文件。
- 原因：修复正常背面剔除实际变为正面剔除的问题；让生产代码和 GPU 回归共用同一状态转换，避免测试再次绕开错误所在层。
- 影响：使用单面材质的 3D 网格现在正确保留外表面；render_backend 对外接口不变，深度、光照和 MSAA 流程不变。

### engine/render/include/rain/render/d3d11/d3d11_rasterizer_state.hpp（新增）
- 新增函数：rain::detail::make_d3d11_rasterizer_desc(const pipeline_state_desc&)。
- 改动：正确映射 none -> D3D11_CULL_NONE、front -> D3D11_CULL_FRONT、back -> D3D11_CULL_BACK。保留 FrontCounterClockwise、DepthClipEnable、MultisampleEnable 和实心填充设置。
- 原因：枚举名表示要剔除的面，不是需要保留的面。将转换集中为可直接参与实际 GPU 测试的内部函数。
- 影响：负缩放仍由既有 front_counter_clockwise 翻转补偿；双面/不剔除保持不变，无需修改模型索引或法线。

### engine/render/CMakeLists.txt
- 修改 rain_render 的公开头文件登记，加入 d3d11_rasterizer_state.hpp。
- 原因：新状态转换头文件成为后端与测试共用的内部实现。
- 影响：构建目标与外部链接方式不变，没有新增测试可执行程序。

### tests/render_3d_tests.cpp
- 新增 test_cube_surface_culling，声明 GPU 回归入口 test_cube_rasterization，并在 main 中调用。
- 改动：通过真实 mesh_3d_registry::create_cube 取得24个顶点、36个索引，检查12个三角形几何法线与顶点法线一致且朝外。
- 改动：通过 render_system_3d 实际提交取得普通、镜像和双面材质的管线描述，传入离屏 GPU 检查。
- 原因：已有 recording_backend 测试只能看到引擎描述，未检测 D3D11 后端将 front/back 映射颠倒的问题。
- 影响：扩充现有 rain_3d_regressions，不改变运行时接口。

### tests/pbr_shader_tests.cpp
- 新增 test_cube_rasterization，复用 warp_renderer 的 D3D11 WARP 设备、生产 3D 顶点着色器及浮点读回目标。
- 改动：创建深度缓冲，使用共享生产 rasterizer 转换，实际绘制立方体；诊断像素着色器直接输出世界位置，使判断不依赖灯光和材质颜色。
- 改动：从±X、±Y、±Z六个方向，分别验证背面剔除、负缩放背面剔除、双面绘制、正面剔除，共24种像素检查。
- 判断：前三种模式应显示靠近相机的外表面；主动剔除正面时应显示远侧表面。
- 原因：既有 PBR 像素测试关闭了面剔除，无法发现本次错误。新增检查同时约束正反面映射、绕序、镜像补偿与深度遮挡。
- 影响：在无窗口的真实 D3D11 光栅化管线中执行；保留原 PBR 色彩与材质回归。

+namespace rain::detail {
+// Shared by production pipeline creation and offscreen D3D11 pixel regressions.
+[[nodiscard]] inline D3D11_RASTERIZER_DESC make_d3d11_rasterizer_desc(const pipeline_state_desc& desc) {
+    D3D11_RASTERIZER_DESC raster{};
+    raster.FillMode=D3D11_FILL_SOLID;
+    // CullMode names identify the faces to discard, not the faces to keep.
+    switch (desc.cull_mode) {
+    case render_cull_mode::none: raster.CullMode=D3D11_CULL_NONE; break;
+    case render_cull_mode::front: raster.CullMode=D3D11_CULL_FRONT; break;
+    case render_cull_mode::back: raster.CullMode=D3D11_CULL_BACK; break;
+    }
+    raster.FrontCounterClockwise=desc.front_counter_clockwise;
+    raster.DepthClipEnable=TRUE;
+    raster.MultisampleEnable=TRUE;
+    return raster;
+}
