### 2. 逐文件变更说明

#### engine/asset/CMakeLists.txt
- 修改目标：rain_asset。
- 改动内容：将 rain_render 从 PRIVATE 依赖改为 PUBLIC 依赖，rain_core 保持实现侧 PRIVATE 依赖。
- 修改原因：gltf_model_3d.hpp 和 texture_asset_registry.hpp 的公共接口直接暴露 render/runtime 类型，消费者需要获得传递 include/link 信息。
- 影响范围：只链接 rain_asset 的调用方现在也能正确包含其公共头文件。

#### engine/asset/include/rain/asset/gltf_model_3d.hpp
- 修改数据结构：gltf_model_3d_instance。
- 修改函数：instantiate_gltf_model_3d、destroy_gltf_model_3d。
- 改动内容：统一 owned_meshes/owned_materials 命名；将加载和销毁声明移出实例结构体，改为 rain 命名空间自由函数；修复 nodiscard 和 instantiate 拼写。
- 修改原因：原声明与 cpp 定义及 sample 调用方式不一致，会产生编译或链接错误。
- 影响范围：调用方统一使用 rain::instantiate_gltf_model_3d 和 rain::destroy_gltf_model_3d。

#### engine/asset/src/gltf_model_3d.cpp
- 修改函数：convert_gltf_matrix_to_lh、find_attribute、import_primitive_mesh、import_material、resolve_material、instantiate_node、instantiate_gltf_model_3d、destroy_gltf_model_3d。
- 改动内容：
  - 修复 glTF 列主矩阵到引擎行向量左手矩阵的转换，Z 轴和层级变换可以正确转换。
  - 修复 attribute index 比较、POSITION/NORMAL/TEXCOORD_0 accessor 读取和顶点字段拼写。
  - 翻转三角形绕序以匹配左手坐标；模型缺少 NORMAL 时按三角形生成平滑法线。
  - 修复 PBR metallic-roughness 字段访问、base color、alpha mode 和外部贴图路径转换。
  - 建立材质缓存，记录 importer 拥有的 mesh/material 句柄，避免重复材质并支持完整释放。
  - 正确创建 root、node、primitive entity，写入 local/world transform 组件、父子关系和 transform/render 标签。
  - 将 printf 风格日志改为当前 log API 支持的单字符串消息。
  - 将公共加载/销毁函数移出匿名命名空间，消除 API 链接问题。
- 修改原因：原 importer 包含多处语法、类型、cgltf 字段和运行逻辑错误，矩阵甚至会被写成全零。
- 影响范围：支持三角形 primitive、POSITION、可选 NORMAL/TEXCOORD_0、外部 URI base-color texture 和基础 alpha mode；暂不支持 embedded image、skin、animation、morph target。

#### engine/core/include/rain/core/math/mat4.hpp
- 修改函数：无逻辑修改。
- 改动内容：规范文件尾换行；保留现有 make_normal_matrix 实现。
- 修改原因：消除文件末尾格式问题。
- 影响范围：无行为变化。

#### engine/render/src/render_system_3d.cpp
- 修改函数：build_camera_frame、make_render_query、make_camera_query、prepare、submit。
- 改动内容：包含 world_transform_3d_component；使用世界 position/forward/up 构造层级相机；读取 world_transform_3d_component::matrix 字段；将 ObjectConstants 尺寸断言从 128 修正为三个 mat4 对应的 192 字节；上传 normal matrix。

- 影响范围：父子层级中的相机和 mesh 会按最终世界矩阵渲染；非均匀缩放使用 normal matrix。

### 3. 行为变化

- CMake 可以找到层级系统头文件并完成生成。
- transform.3d 实体会生成/更新 world_transform_3d_component。
- transform.inherit_parent 子节点正确组合父节点世界矩阵。
- 3D render system 使用最终世界矩阵、世界相机方向和 192 字节 ObjectConstants。
- glTF 三角形 mesh、基础 PBR 颜色、外部 base-color 贴图、节点层级可导入为 ECS 实体。
- 缺失 NORMAL 的 primitive 会自动生成法线。
- glTF 实例销毁会删除创建的实体并释放 owned mesh/material。
- 模型文件不存在时安全返回无效实例，不影响现有 cube 样例继续运行。

### 4. 风险点

- 仓库当前不存在 assets/models/test_model/model.gltf，实际样例只能验证缺失文件容错和原有 cube 渲染；需要提供模型后再做画面验证。
- importer 暂不支持 GLB 内嵌图片/buffer-view image、skin、animation、morph target、多个 UV 集和非 triangle primitive。
- material_3d 的 alpha blend 目前仍受 render_system_3d 固定 pipeline 限制，透明材质尚未按 blend mode 切换 pipeline/排序。
- texture_asset_registry 负责贴图缓存生命周期；destroy_gltf_model_3d 不主动卸载贴图，以避免破坏共享纹理，但长期动态加载大量模型时需要引用计数或显式卸载策略。

### 5. 建议验证方式

已执行并通过：

1. GCC Debug 完整配置与构建：sample_2d_action.exe 链接成功。
2. D3DCompile：mesh_3d.hlsl 的 vertex_main/vs_4_0 与 pixel_main/ps_4_0 均通过。
3. 5 秒隐藏烟雾测试：sample_2d_action 持续运行，无启动即崩溃。
4. 层级矩阵回归：父平移 (1,2,3) + 子局部平移 (4,0,0) 得到世界位置 (5,2,3)。
5. 临时 glTF 回归：三角形模型解析、缺失法线生成、3 个实体/1 个 mesh 创建、层级更新和销毁均通过。
